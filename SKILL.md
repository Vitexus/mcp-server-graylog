---
name: graylog-mcp
description: Query a Graylog 7.1+ server (system info, streams, searches, security events) through the mcp-server-graylog stdio bridge. Use when asked about Graylog logs, streams or events.
---

Tools come from Graylog and depend on its licence and the token's permissions. The bridge is read-only unless `GRAYLOG_READ_ONLY=false`; ask the user before enabling write tools. Give prompts a time range and a stream.
